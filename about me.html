Campus Events Board

Time Frame: 4 weeks

Team Size: 3

Languages Used: HTML, CSS, JavaScript

My Main Contributions:

- Wireframing and Design for All Pages
- Front-end Development for All Pages
- Filter System
- Page Navigation System
- Project Presentation

This is a project that I worked on as part of a small team with 2 other students for the Project Build programme organised by the Code Cafe society at my university, which I was selected for. The aim of this programme was to work in small teams to build a project over a short period of time in order to simulate what collaborative working is like in industry.

My team decided to create a Campus Events Board which students could use to view upcoming events that would be held on campus. It was decided that I would work on frontend development with one of my other teammates working on the backend development for the website. Thus, I first created the wireframe for the different web pages that would make up our Campus Events Board in order to know how the website would be structured and laid out. I then started creating the pages themselves as well as the stylesheet which would dictate how the web pages and the different components within them - e.g. the panels showing the events - would look, making sure to keep it relatively in line with the wireframe. Once multiple pages had been created, I created a navbar at the top of each page which would allow the user to navigate between the different pages and I also made the Campus Events title a link to the home page of the website. I then also used JavaScript to create a filter system which would allow the user to filter the different events on the page by things such as event type, location and date. Alongside this filter system, I also created a searching system with a search bar that allowed the user to search for an event by name and would show any events whose names contained the search term.

What I Learned

Working on this project taught me a lot about working collaboratively on a project such as planning, organising and discussing the project with my teammates, reviewing others' work and how to use GitHub to work on a project with multiple people which I hadn't used before and is something that has been very helpful for me in projects I have done since this one.

During the course of this project I also learned a lot about CSS as while I had used it before, such as when creating this portfolio, this project required me to learn a lot more about CSS in order to make the website look the way the team and I wanted it to. This was also the first project that I had used JavaScript for so I had to learn some of this new programming language as well.

Anti-Apartheid Legacy Trust Project

Time Frame: 4 weeks

Team Size: 6

Languages Used: Blueprint, Unreal Engine

My Main Contributions:

- Prototyping of Mechanics Concepts
- Collating Research
- Presentation of Research and Considerations

This is a project that I worked on as part of a short internship with the Anti-Apartheid Legacy Trust. The Trust tasked myself and my team with creating a concept for a game which they could use in their upcoming museum. We were given a brief which stated that they wanted this game to teach visitors about the history being presented to them through an experience rather than simply testing their knowledge with something such as a quiz game. Alongside our pitch for this game concept, the Trust also wanted us to present research about why gamification in museums may be beneficial to them as well as any considerations that would need to be taken into account both when potentially developing this concept and when presenting it to the public.

My team decided to create a VR game where the player would be able to experience events related to the events of apartheid as well as the Anti-Apartheid movement. The player would experience each event from multiple points of view and would be able to make decisions and complete tasks in each scenario. They would be able to enter each scenario by interacting with a picture or artefact in a virtual museum-like space and they would be returned to this space after completing each event. In this museum space, there would be an NPC called 'The Curator' who would guide the player from one scenario to another, making them think about what they had just experienced, and possibly provide any relevant information the player may need to know before entering an event.

We decided to go with this idea as a VR experience would allow the player to be immersed in the events and information being presented to them. This meant that the player would be directly engaged with the history they are learning about as they would be learning through interacting with the different events and scenarios they are experiencing.

For this project, I collated and presented research about how gamification can be beneficial for museums and how it is being used in museums and heritage institutions already and I also presented the considerations that the Trust would need to have with having a VR experience in their museum. I also made a prototype for the entering events mechanic where the player would interact with a picture or an artefact to enter an associated scenario.

What I Learned

During the course of this project, I not only furthered my teamworking skills but I also learned what it was like working with a client as this was something I had never done before. The team had weekly meetings with a member of the Trust and sought feedback from them throughout the project before the final pitch meeting through emails. All of this gave me more experience and insight into what is expected when working and communicating with a client.

Throughout this project, I also enjoyed learning a lot about the events of apartheid as well as the anti-apartheid movement, both in Britain and globally. This was a subject that I didn't have a lot of knowledge on before working on this project so I learned a lot through the research I did when working on this project.

During the course of this project I also learned more about how VR development in Unreal Engine works as, while I had experience developing a VR project in Unity, this was the first time I had developed a VR project using Unreal Engine.
