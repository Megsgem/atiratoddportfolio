About the Project

Time Frame: 8 weeks

Team Size: 1

Languages/Libraries used: C++, DirectX 11

Main Contributions:

- Simulation of rigidbody physics
- 3 methods of collision detection
- Collision resolution
- Simulation of rotational forces using Quaternions


This is a project I created as part of the Applied Maths for Games module during my second year of university.

Collision Detection

One of the main things I worked on during this project were different methods of collision detection for the different objects in my project. I wanted to do this so that the simulation would be more accurate i.e. each object would have a collider which aligned with the shape of the object. The three different colliders I decided to create for this project were sphere colliders, axis-aligned bounding boxes and plane colliders.
