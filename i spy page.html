About the Game

Time Frame: 7 days

Team Size: 1

Language/Engine Used: C#, Unity

This is the game I made for the Secret Level Jam, a jam where the game submitted had to have a secret level. The jam's theme was 'Watch Me' so I decided to make a game set in a world where everyone is always being watched.

Eye Movement

One of the features of this game that I focused on while making it was the movement of the eyes in the background. While this doesn't currently affect the gameplay, it was something I felt would be important for the environment and atmosphere of the game as it would emphasise the feeling of the player being watched.
