About the Project

Time Frame: 8 weeks

Team Size: 1

Languages/Libraries used: C++, DirectX 11, HLSL

Main Contributions:

- Camera System
- Alpha Clipping and Transparency

This is a project I created as part of the Real Time Rendering Framework module in my second year of university. Over the course of this module I was given a framework and was tasked with creating a scene which would showcase a variety of techniques and skills that would be used when building a graphics engine (renderer??) such as implementing lighting, cameras, transparency and writing shaders using HLSL.

Camera System

As part of this module, I made different types of cameras that could be used to view the scene as cameras are a vital part of all games and are needed for the player to be able to view the world around them. For this project, I wanted there to be multiple cameras that the player could use to view the scene from different angles, with some of the cameras being stationary and others being able to move.
