About the Game

Time Frame: 36 hours

Team Size: 1

Language/Engine Used: C#, Unity

This is the game I made for the UKIE Student Game Jam 2025 where the theme of the jam was 'Contrast'. The duration of the jam was 36 hours during which I used C# and Unity to program all of the mechanics for the game including the 'switching' mechanic which is central to the gameplay. Since the end of the jam, I have done further work on this game fixing some bugs which remained in the game by the end of the jam and adding some new things which I wasn't able to add during the jam time.

The game is a relatively simple platformer where you have to traverse through each level in order to find the exit and move on to the next. However, in order to do so, the player must use their ability to switch between light and dark as some things only exist in the dark and others only exist in the light.

Switching Mechanic

One of the main mechanics of this game is the mechanics that allows the player to switch between light and dark. Not only is this mechanic the way that the game fits into the theme of the jam as it means that the contrast between light and dark is a central part of the game but it also allows the player to use platforms that they previously couldn't access.
