Campus Events Board

Time Frame: 4 weeks

Team Size: 3

Languages Used: HTML, CSS, JavaScript

My Main Contributions:

- Wireframing and Design for All Pages
- Front-end Development for All Pages
- Filter System
- Page Navigation System

This is a project that I worked on as part of a small team with 2 other students for the Project Build programme organised by the Code Cafe society at my university, which I was selected for. The aim of this programme was to work in small teams to build a project over a short period of time in order to simulate what collaborative working is like in industry.

My team decided to create a Campus Events Board which students could use to view upcoming events that would be held on campus. It was decided that I would work on frontend development with one of my other teammates working on the backend development for the website. Thus, I first created the wireframe for the different web pages that would make up our Campus Events Board in order to know how the website would be structured and laid out. I then started creating the pages themselves as well as the stylesheet which would dictate how the web pages and the different components within them - e.g. the panels showing the events - would look, making sure to keep it relatively in line with the wireframe. Once multiple pages had been created, I created a navbar at the top of each page which would allow the user to navigate between the different pages and I also made the Campus Events title a link to the home page of the website. I then also used JavaScript to create a filter system which would allow the user to filter the different events on the page by things such as event type, location and date.

What I Learned

Working on this project taught me a lot about working collaboratively on a project such as planning, organising and discussing the project with my teammates, reviewing others' work and how to use GitHub to work on a project with multiple people which I hadn't used before and is something that has been very helpful for me in projects I have done since this one.

During the course of this project I also learned a lot about CSS as while I had used it before, such as when creating this portfolio, this project required me to learn a lot more about CSS in order to make the website look the way the team and I wanted it to. This was also the first project that I had used JavaScript for so I had to learn some of this new programming language as well.
