About the Game

Time Frame: 8 weeks

Team Size: 23

Language/Engine Used: C#, Unity

Main Contributions:

- UI Programming
- Checkpoints
- Player Death & Respawn/Restart System

This is a game I made as part of a team during my Junior Collaborative Games Development module during my second year of university. During the course of this module, I worked with other members of the team, across various different disciplines such as art and design, to implement the different aspects of the game that I was tasked with creating by senior members of the team.

It is a 3D speedrunning platformer game where you play as Cursor and must use your different abilities such as wall running and grappling to traverse the techno-wave cyberspace environment as fast as possible.

Main Menu UI

One of my main tasks and contributions to this project was the programming for the UI in the main menu. This included not only the backend for UI of the main menu screen itself but also for the related screens which the buttons of the main menu screen lead to. The designers within the team had specified that these would be a level selection screen, a controls screen and a settings screen.

I first started working on the functionality for the main menu screen itself such as making sure the player could navigate the buttons on this screen using either the keyboard or a controller or a mouse.
