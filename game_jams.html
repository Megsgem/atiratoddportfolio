Fishing Horror Jam - Secrets of Stillwater Lake

Time Frame: 11 days

Team Size: 1

I made this game for the Fishing Horror Jam - a game jam with no specific theme but with the rules that fishing had to be central to the game and horror had to be incorporated in some way. I programmed all of the features and mechanics of this game such as the fishing mechanic, shop system and guide book feature.

Secret Level Jam - I Spy

Theme: Watch Me

Time Frame: 7 days

Team Size: 1

This is the game I made for the Secret Level Jam. This was a game jam where the game created had to have a secret level with the theme of the jam being 'Watch Me'. I participated in this jam as an individual, not as part of a team, and I programmed and implemented features of the game such as the player's movement, the movement of the eyes watching the player, a basic collectibles feature and the way the levels of the game are managed.
