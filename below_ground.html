About the Game

Time Frame: 8 weeks

Team Size: 1

Language/Library used: C++, SDL2

Main Contributions:

- Collisions
- Layout Switching Feature
- Player Movement
- Enemy Behaviour
- Screen Management System

I made this game as part of the Bespoke Platform Development module that I took in my first year of univeristy. In this module we were given a framework upon which we had to build our game although this framework didn't have a lot of functionality to begin with. The game produced from this module was also meant to be playable on an Evercade console - a type of console that is sepcialised for retro-style games - meaning that the game had to be able to work with the low amount of memory this console had.

In order to create this game I not only had to program the mechanics and features of the game (e.g. the enemy behaviour and making the layout of the room change) but I also had to create things such as the components that could be added to the player (e.g. colliders and rigidbodies) and the tilemap class.

Room Layout Switching

What I Learned

Making a game for a console such as an Evercade not only helped me learn more about what the process of building a game for a specific console can be like, but it also made me consider just how important memory management and proper optimisation can be, especially when making games for platforms with a lower memory capacity.
